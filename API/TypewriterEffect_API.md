# TypewriterEffect API

## 功能

负责文本打字机效果的播放、跳过和重置；支持在打字过程中锁定玩家拖拽输入，并在打字完成后恢复输入。

## API

| 接口                        | 功能                                     | 调用方        |
| --------------------------- | ---------------------------------------- | ------------- |
| StartTyping(string, Action) | 开始播放打字机效果，支持完成回调         | 对话/提示系统 |
| SkipTyping()                | 跳过当前打字，立即显示全文并执行完成回调 | 对话/提示系统 |
| ClearText()                 | 清空当前文本并停止打字流程               | 对话/提示系统 |
| IsTyping                    | 获取当前是否正在打字                     | 对话/提示系统 |

## 调用规范

- 所有文本打字效果应通过 `TypewriterEffect` 的公开接口进行控制。
- `StartTyping` 会在文本为空时直接完成回调；当已有打字正在进行时会中断当前打字并重新开始。
- `SkipTyping` 会立即显示完整文本，并在必要时解除输入锁定。
- `ClearText` 会停止打字流程、清空文本，并恢复通过 `InputManager` 锁定的输入。
- 打字过程中会根据标点符号延长停顿时间，并尝试播放 `AudioManager` 的打字音效。
- 禁止直接修改内部 `fullText`、`isTyping`、`typingCoroutine` 或 `textComponent` 状态。
